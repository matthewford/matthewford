## Now building: Corenote

I'm currently focused on [Corenote](https://corenote.ai/), a workspace where people and AI agents plan, track and ship work together. It replaces tools like Linear and Notion with one built for agent-based workflows. Agents work in the open and people stay in the loop on the decisions that matter.

We're starting with software teams, since that's where agents have the most traction today. Corenote is in private beta, and we're looking for design partners and early testers. [Apply for the beta](https://corenote.ai/).
